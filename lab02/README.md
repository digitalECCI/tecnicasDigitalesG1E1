## 1. Introducción

El sumador combinacional es uno de los bloques constructivos fundamentales en la aritmética digital y las Unidades Aritmético Lógicas (ALU). Un sumador completo de 1 bit (*Full Adder*) es un circuito combinacional que realiza la suma aritmética de tres bits de entrada: los operandos $A$ y $B$, y un acarreo de entrada $C_i$ (Carry-in). A partir de estos tres bits, el circuito produce dos salidas: la suma $S_o$ (Sum) y el acarreo de salida $C_o$ (Carry-out).

Las expresiones booleanas que rigen el comportamiento del sumador de 1 bit son:

$$S_o = A \oplus B \oplus C_i$$

$$C_o = (A \cdot B) + (A \cdot C_i) + (B \cdot C_i)$$

Para extender la capacidad de suma a palabras binarias de mayor longitud, como en este caso a 4 bits ($A[3:0]$ y $B[3:0]$), se emplea una arquitectura en cascada conocida como **Sumador de Acarreo Encascadado** (*Ripple Carry Adder*). En esta topología, cuatro bloques sumadores de 1 bit se interconectan de forma secuencial de modo que el acarreo de salida ($C_o$) de la etapa del bit menos significativo ($LSB$) se conecta al acarreo de entrada ($C_i$) de la etapa del bit siguiente.

## 2. Descripción de Hardware

La arquitectura del sumador de 4 bits se implementa de forma jerárquica mediante la técnica de diseño modular en Verilog (HDL). Esta metodología se divide en dos capas: el módulo base de 1 bit y el módulo de nivel superior (*Top-Level*) de 4 bits.

### 2.1 Módulo Elemental: Sumador de 1 bit (`Sumador_1bit`)

Este módulo implementa la lógica combinacional básica de un *Full Adder* para procesar los bits de entrada `A`, `B` y el acarreo de entrada `Ci`. Genera la salida de suma `So` mediante la operación XOR entre los tres bits de entrada, y el acarreo de salida `Co` mediante la lógica de mayoría empleando asignaciones continuas (`assign`).

```verilog
// Módulo de 1 bit que ya se tiene
module Sumador_1bit (
    input A,
    input B,
    input Ci,
    output So,
    output Co
);
    assign So = A ^ B ^ Ci;
    assign Co = (A & B) | (A & Ci) | (B & Ci);
endmodule

// Módulo Top: Sumador de 4 bits instanciado
module Sumador_4bit (
    input  [3:0] A,
    input  [3:0] B,
    input        Ci,
    output [3:0] So,
    output       Co
);

    // Cables internos para propagar los acarreos intermedios
    wire C0, C1, C2;

    // Instancia bit 0 (el menos significativo - LSB)
    Sumador_1bit bit0 (
        .A(A[0]),
        .B(B[0]),
        .Ci(1'b0), // El primer acarreo de entrada es 0
        .So(So[0]),
        .Co(C0)
    );

    // Instancia bit 1
    Sumador_1bit bit1 (
        .A(A[1]),
        .B(B[1]),
        .Ci(C0),
        .So(So[1]),
        .Co(C1)
    );

    // Instancia bit 2
    Sumador_1bit bit2 (
        .A(A[2]),
        .B(B[2]),
        .Ci(C1),
        .So(So[2]),
        .Co(C2)
    );

    // Instancia bit 3 (el más significativo - MSB)
    Sumador_1bit bit3 (
        .A(A[3]),
        .B(B[3]),
        .Ci(C2),
        .So(So[3]),
        .Co(Co)
    );

endmodule
```
